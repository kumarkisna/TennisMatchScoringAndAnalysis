---
name: Saved player links
description: Local persistence and navigation for profile URLs attached to tennis players.
---

Saved profile URLs belong to each device-only player record and must remain directly openable from the player list.

**Why:** The user reported that saved player links were missing and asked that users be able to navigate to them.

**How to apply:** Preserve the URLs when editing or restoring local player records, and open them through the device's link handler.
