---
name: Vibrant local themes
description: The user wants visibly varied, vivid themes and an editable custom palette that works offline.
---

## Rule
Offer distinct vibrant palettes as well as classic themes, and let the user edit primary, accent, and background colors locally. Provide a global soft-to-vivid tone control and per-color depth sliders for custom palettes. Preserve the original default palette.

**Why:** The user found the earlier theme groups too similar and dull, asked for customization, and requested controls to soften or intensify a selected theme and deepen individual custom colors.

**How to apply:** Keep theme selection and custom colors on-device, provide accessible color choices plus hex entry, and avoid changing the saved default unless asked.
