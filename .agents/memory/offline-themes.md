---
name: Vibrant local themes
description: The user wants visibly varied, vivid themes and an editable custom palette that works offline.
---

## Rule
Offer distinct vibrant palettes as well as classic themes, and let the user edit primary, accent, and background colors locally through visual swatches and named color previews, not hex-code fields. Provide a global soft-to-vivid tone control and per-color depth sliders for custom palettes. Preserve the original default palette.

**Why:** The user found the earlier theme groups too similar and dull, asked for customization, requested tone and depth controls, and said hex codes are confusing and color-grid selection is preferable.

**How to apply:** Keep theme selection and custom colors on-device, provide accessible visual color choices, and avoid changing the saved default unless asked.
